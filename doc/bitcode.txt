Brainfunk bitcode: instruction set reference
============================================

doc/bincode.txt gives the binary encoding of these instructions.


Machine state
-------------

memory[MEMSIZE]   8-bit cells, all zero at reset.  MEMSIZE is a power of two.
base_ptr          Index into memory, zero at reset.
pc                Index into the program, zero at reset.

Only M and F change base_ptr.  No other instruction moves it.

All cell arithmetic is modulo 256.


Effective address
-----------------

EA(offset) = (base_ptr + sign_extend(offset)) mod MEMSIZE

Every memory access goes through EA(); there is no access to a cell other than
by adding a signed offset to base_ptr.


Three kinds of offset
---------------------

addr_offset, src_offset, test_offset
                  Select a cell relative to base_ptr, through EA().
move_offset, step Added to base_ptr, modulo MEMSIZE.
jump_offset       Added to pc, relative to the NEXT instruction: a taken jump
                  continues at pc + 1 + jump_offset.


Instructions
------------

Mnemonic and operands are the text of a listing, see "Program images" in doc/bincode.txt.  Instructions
without a stated effect on pc continue at pc + 1.

X
    Illegal instruction; see Illegal instructions below.

A addr_offset, data
    memory[EA(addr_offset)] += data

S addr_offset, data
    memory[EA(addr_offset)] = data

MUL addr_offset, src_offset, factor
    memory[EA(addr_offset)] += memory[EA(src_offset)] * factor
    The source is read before the destination is written.

F test_offset, step
    while memory[EA(test_offset)] != 0:
        base_ptr = (base_ptr + sign_extend(step)) mod MEMSIZE
    Takes a data-dependent number of iterations and never ends if the condition
    never becomes false.  EA() is recomputed from the new base_ptr each time.

M move_offset
    base_ptr = (base_ptr + sign_extend(move_offset)) mod MEMSIZE

JE test_offset, jump_offset
    if memory[EA(test_offset)] == 0: pc = pc + 1 + sign_extend(jump_offset)

JN test_offset, jump_offset
    if memory[EA(test_offset)] != 0: pc = pc + 1 + sign_extend(jump_offset)

IO addr_offset, operation
    operation 0: memory[EA(addr_offset)] = next input byte, or 0 at end of input
    operation 1: output memory[EA(addr_offset)]
    Other values are illegal.

H
    Halt.  Sticky: the machine stays halted with pc on the H instruction.


Illegal instructions
--------------------

A word that doc/bincode.txt does not define is illegal: opcode X, a reserved
opcode, a non-zero reserved field, an IO operation other than 0 or 1, or a
SRUN count of 0.

Executing one traps: nothing changes, and the machine stays stopped with pc on
that word.  Fetching one does not, so an image may hold illegal words that are
never reached.

An image must end in H or an illegal word, and no jump may leave it.  Behaviour
of any other image is undefined.


Fused instructions
------------------

These only make one instruction out of a pair that is otherwise common.  They
do nothing the instructions above cannot.

MULC addr_offset, src_offset, factor
    value = memory[EA(src_offset)]
    memory[EA(addr_offset)] += value * factor
    memory[EA(src_offset)] = 0
    MUL followed by S src_offset, 0.  If both offsets name one cell, it ends at 0.

DJN test_offset, jump_offset
    memory[EA(test_offset)] -= 1
    if memory[EA(test_offset)] != 0: pc = pc + 1 + sign_extend(jump_offset)
    A test_offset, 255 followed by JN test_offset, jump_offset.

MJN test_offset, move_offset, jump_offset
    base_ptr = (base_ptr + sign_extend(move_offset)) mod MEMSIZE
    if memory[EA(test_offset)] != 0: pc = pc + 1 + sign_extend(jump_offset)
    M move_offset followed by JN test_offset, jump_offset.  EA() uses the moved
    base_ptr.

SRUN addr_offset, data, count
    for i in 0 .. count-1:
        memory[EA(addr_offset + i)] = data
    S on consecutive cells, count is 1 to 255.  Takes a data-dependent number of
    memory writes.
